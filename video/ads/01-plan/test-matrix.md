## Suggested production order

1. R01 first. It proves the formula, builds the shared kit in `video/src/ads/kit`, and sets the VO and caption pipeline.
2. R06 and R02 next (offer and blueprint reuse the same `OfferCard` and `BlueprintScene`).
3. R03, R04, R05 reuse the kit with new hooks and mechanism visuals.
4. Statics S01-S07 in parallel with the reels, since they only need the brand tokens and offer.
